## 🚀 Proyectos

### 🦸 Superhero Application Form
Aplicación full stack para crear perfiles de superhéroes: se seleccionan poderes y se ajustan niveles dinámicamente. Backend en Node.js + Express + SQLite con API REST (CRUD) para guardar y listar héroes.
- **Demo:** `/superhero`
- **Código:** [`/superhero`](./superhero)

### ☁️ Weather App
Consulta el clima en tiempo real. El frontend consume un backend propio en Node.js/Express que actúa como proxy hacia el servicio externo de clima.
- **Demo:** `/weather`
- **Código:** [`/weather`](./weather)

### 🏍️ Motorcycle Shop
Galería de motocicletas construida en TypeScript orientado a clases, con buscador en tiempo real. El catálogo se sirve desde un backend propio en Node.js/Express.
- **Demo:** `/Motorcycle Shop`
- **Código:** [`/Motorcycle Shop`](./Motorcycle%20Shop)

### ⚽ Football Card Builder
Crea y personaliza tarjetas de jugadores de fútbol con componentes reutilizables en React + TypeScript. Backend en Node.js + Express + SQLite con API REST (CRUD completo) para guardar, listar y eliminar tarjetas.
- **Demo:** `/football-card-builder`
- **Código:** [`/football-card-builder`](./football-card-builder)
