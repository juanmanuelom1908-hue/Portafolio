# Portafolio

Repositorio con proyectos web desarrollados como práctica y muestra de habilidades en TypeScript, JavaScript y desarrollo frontend.

## 🚀 Proyectos

### 🏍️ Motorcycle Shop
Tienda de motocicletas construida con TypeScript.
- **Demo en vivo:** [Ver proyecto](https://juanmanuelom1908-hue.github.io/Portafolio/motorcycle-shop/)
- **Código:** [`/Motorcycle Shop`](./Motorcycle%20Shop)

### 🦸 Powers Form
Formulario interactivo de superhéroes.
- **Demo en vivo:** [Ver proyecto](https://juanmanuelom1908-hue.github.io/Portafolio/superhero/)
- **Código:** [`/powers.form`](./powers.form)

### ⛅ Weather Project
Aplicación de consulta del clima.
- **Demo en vivo:** [Ver proyecto](https://juanmanuelom1908-hue.github.io/Portafolio/weather/)
- **Código:** [`/weather-project`](./weather-project)

## 🛠️ Tecnologías

- TypeScript
- JavaScript
- React
- Tailwind CSS
- HTML / CSS
- GitHub Actions (deploy automático a GitHub Pages)

## 📦 Cómo correr el proyecto localmente

```bash
git clone https://github.com/juanmanuelom1908-hue/Portafolio.git
cd Portafolio
npm install
```

Para compilar el proyecto de TypeScript (Motorcycle Shop):

```bash
npx tsc
```
