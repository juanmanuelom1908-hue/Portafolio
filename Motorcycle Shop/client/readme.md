# Motorcycle Shop 🏍️

Aplicación web desarrollada con TypeScript y Tailwind CSS que consume una API de motocicletas, muestra las motocicletas dinámicamente y permite filtrarlas por nombre.

## Tecnologías

- TypeScript
- Tailwind CSS
- HTML
- Fetch API
- DOM Manipulation

## Funcionalidades

- Consumo de datos desde una API.
- Renderizado dinámico de motocicletas.
- Contador de resultados.
- Filtro de motocicletas por nombre.
- Diseño responsive con Tailwind CSS.
