# 🌤 Weather App

App web que muestra el clima en tiempo real de cualquier ciudad del mundo.

## 🔴 Demo
> Próximamente en GitHub Pages

## 📸 Screenshot
![Weather App](image.png)

## ✨ Funcionalidades
- Buscar cualquier ciudad por nombre
- Ciudades rápidas con un click
- Temperatura en °C y °F
- Muestra: sensación térmica, humedad, viento y ráfagas
- Loading spinner mientras carga
- Manejo de errores en pantalla

## 🛠 Tecnologías
- HTML5
- Tailwind CSS
- JavaScript (Vanilla)
- API: [freeCodeCamp Weather Proxy](https://weather-proxy.freecodecamp.rocks)

## 🚀 Cómo usarlo
1. Escribe el nombre de una ciudad en el buscador
2. Presiona **Search** o **Enter**
3. También puedes usar los botones rápidos de ciudades populares
